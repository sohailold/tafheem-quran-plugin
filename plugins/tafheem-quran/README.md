# tafheem-quran

Connects Claude to the free, read-only MCP server of tafheemulquran.net
(`https://tafheemulquran.net/mcp`, 15 tools, no sign-in) and adds the
`tafheem-research` skill. Claude can then search and quote Sayyid Abul A'la
Maududi's Tafheem-ul-Quran (Urdu original and English edition, with his notes),
the six major hadith collections, a library of Islamic books, the Nizamaat
topics and Islamic history, giving a link to the source page for every quote
and keeping Maududi's words separate from its own explanation.

Install in Claude Code:

    /plugin install tafheem-quran --marketplace sohailold/tafheem-quran-plugin

No setup is needed after installing. Try: "Show Tafheem-ul-Quran's translation
of 2:255 with its notes" or «زکوٰۃ کے بارے میں قرآن اور تفہیم القرآن کیا کہتے ہیں؟».
